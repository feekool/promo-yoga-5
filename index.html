Как установить?

  1. Зайдите на GitHub и создайте аккаунт.
  2. Создайте новый репозиторий с именем your-yoga-school.
  3. Загрузите шаблон Feekool Yoga в репозиторий.
  4. Включите GitHub Pages в настройках репозитория.
  5. Готово! Ваша платформа доступна по адресу https://your-yoga-school.github.io.
